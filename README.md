# pairwise-vehicle-tire

赛车过弯时轮胎像冰面、漂移突然回正、悬挂过坎弹飞：轮胎侧偏用线性；抓地力不随载荷；滑移率用速度差；漂移判定按手刹；悬挂弹簧刚度固定；阻尼和弹簧不匹配；车身重心不参与；ABS 和引擎扭矩打架；路面摩擦统一；固定步长和渲染帧不同步。game/vehicle_tire.py 是核心，tests/test_vehicle_tire.py 15个红。要修的是：魔术公式侧偏；载荷转移；滑移率；漂移角；弹簧刚度；阻尼匹配；重心惯量；ABS 扭矩协调；路面摩擦；固定步长。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
